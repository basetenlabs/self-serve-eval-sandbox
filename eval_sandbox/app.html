How a run works

1. Find

Recent merged PRs that change both code and tests. The PR's text, or the issue it closes, is the request; the code just before the merge is the starting point.

2. Check

Each PR's tests must fail before the change and pass after it, in the same image the models use. PRs that don't are left out: a setup problem, not a model's.

3. Run

Each model works on each PR in a fresh Blaxel sandbox through Claude Code, with GitHub and package registries blocked so it can't look up the answer.

4. Grade

The agent's sandbox is deleted, then a fresh verifier runs the PR's hidden tests on its change and an AI judge compares it with the merged one. Solved means both agree.

Runs are ordinary pr-eval run processes, so they keep going if this page is closed. The same from a terminal: pr-eval run --quick or pr-eval run owner/repo --models claude-opus,deepseek-v4.1-flash.
